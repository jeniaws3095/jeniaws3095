## Production Work

### AWS Infrastructure Case Study — E-Commerce Platform
**[Shopify-Production-Infrastructure](https://github.com/jenidevops30/Shopify-Production-Infrastructure)**

Multi-tier AWS infrastructure for a high-traffic Laravel/PHP e-commerce platform.

- **Stack**: ALB · EC2 Auto Scaling · RDS MariaDB (Multi-AZ) · VPC · Route 53 · Cloudflare · CloudWatch · IAM
- **Availability**: ≥99.9% uptime over 6 months including peak promotional events
- **Performance**: Reduced p95 latency ~55% (420ms → 190ms) via ALB tuning and connection pooling
- **Cost**: Cut EC2 spend ~30% through right-sizing and Auto Scaling threshold tuning
- **Incidents**: Resolved Auto Scaling oscillation and RDS connection exhaustion — both documented with root cause and fix

→ Full technical case study + Terraform demo environment inside the repo
